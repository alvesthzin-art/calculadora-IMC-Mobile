# 📱 Calculadora de IMC (Jetpack Compose)

Uma aplicação mobile moderna e interativa desenvolvida em Kotlin para calcular o Índice de Massa Corporal (IMC) e classificar a faixa de peso do utilizador.

### 🧠 Conceitos aplicados:
* **Jetpack Compose:** Construção de interface declarativa e moderna para Android.
* **Gerenciamento de Estado:** Uso de `remember` e `mutableStateOf` para atualização reativa dos componentes na UI.
* **Layouts Reativos:** Organização e alinhamento visual utilizando `Column`, `Row`, `Box`, `Card` e `Spacer`.
* **Componentes Material 3:** Aplicação de componentes padrão como `Scaffold`, `OutlinedTextField` e `Button`.
* **Estrutura de Decisão (`when`):** Lógica condicional para cálculo numérico do IMC e atribuição dinâmica do resultado e cores da interface.
